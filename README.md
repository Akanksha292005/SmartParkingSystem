# Smart Parking Management System

A full-stack Smart Parking Management System built using Flask and SQLite to streamline parking operations through real-time slot monitoring, QR-based ticketing, automated billing, and administrative analytics.

## Features

### User Features

* Secure User Registration & Login
* Password Hashing for Authentication
* Real-Time Parking Slot Availability
* Floor-Wise Slot Management
* Vehicle Type Selection (Car/Bike)
* QR Code-Based Ticket Generation
* Unique Booking ID Generation
* Automated Parking Fare Calculation
* Booking History Tracking
* Booking Cancellation
* Simulated Payment System (UPI, Card, Wallet, Cash)

### Admin Features

* Live KPI Dashboard
* Occupancy Monitoring
* Revenue Tracking
* Active Vehicle Monitoring
* Check-In / Check-Out Management
* User Management
* Booking Search & Filtering
* Slot Addition & Control
* Floor Occupancy Analytics
* Revenue Analytics (7-Day & 30-Day)
* Peak Hour Analysis
* Vehicle Distribution Statistics

## System Workflow

1. User Registration/Login
2. View Available Parking Slots
3. Select Floor and Vehicle Type
4. Book Parking Slot
5. Generate QR-Based Parking Ticket
6. Vehicle Check-In
7. Automated Fare Calculation
8. Vehicle Check-Out
9. Payment Processing
10. Booking History Management
